# Termux Banner

## Kurulum

```bash
git clone https://github.com/otizmlicoder/Termux_banner.git
cd Termux_banner
chmod +x install.sh
./install.sh
```

Kurulum sırasında banner metnini, alt başlığı, logo ve font tercihini soracak. Bitince:

```bash
exec bash
```

Ayarları sonra değiştirmek istersen:

```bash
nano ~/.termux_banner.conf
```
